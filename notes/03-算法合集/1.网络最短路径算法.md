# 最短路径算法

[图论：图的四种最短路径算法_图的最短路径算法_钟一淼的博客-CSDN博客](https://blog.csdn.net/m0_64045085/article/details/123504469)

## Dijksyta算法

[743. 网络延迟时间 - 力扣（LeetCode）](https://leetcode.cn/problems/network-delay-time/)

**问题：** n个点，选一个点k，求k到所有点的最短路径

**简述：** 

1. 先初始化 [n] [n] 的数组 g，g [i] [j] 表示的是i 到 j 的有向边。 初始距离全部为 MAX_VALUE/2。(防止溢出)然后根据给出的边，重新赋值。
1. 初始化dist[n] 表示从给定的点到所有点的最短距离。初始距离全部为MAX_VALUE/2。给定的点自身为0.
1. 设置遍历数组used[n]从给定的点k开始遍历，更新距离数组。
1. 选取没有使用过的点中最近的点，重复3.(使用优先队列 **PriorityQueue**)
1. 选取数组中的最大值。

 

```java
    public int networkDelayTime(int[][] times, int n, int k) {
        //初始化边矩阵
        final int INF = Integer.MAX_VALUE/2;
        int[][] g = new int[n][n];
        for(int[] arr:g){
            Arrays.fill(arr, INF);
        }
	
        for(int x = 0 ; x < times.length; x++){
            int start = times[x][0]; int end = times[x][1];
            g[start - 1][end - 1] = times[x][2];
        }
		
        //初始化距离矩阵
        int[] dist = new int[n];
        Arrays.fill(dist, INF);
        dist[k - 1] = 0;

        //初始化使用的点矩阵 以及 优先级队列
        boolean[] used = new boolean[n];
        PriorityQueue<int[]> s = new PriorityQueue<>((a, b) -> a[1] - b[1]);
        s.offer(new int[] {k - 1, dist[k - 1]});
        used[k - 1] = true;
        
        //循环直到优先级队列中没有值
        while(!s.isEmpty()){
            int node = s.poll()[0];
            s.clear();
            used[node] = true;
            for(int i = 0; i < n; i++){
                dist[i] = Math.min(dist[i], dist[node] + g[node][i]);
                if( dist[i] < INF && used[i] != true){
                    s.offer(new int[] {i, dist[i]});
                }
            }
        }
        
        int res = Arrays.stream(dist).max().getAsInt();
        return res < INF ?res:-1;


    }
```
