# Morris算法(二叉树遍历)

**一句话概括**

Morris算法是遍历二叉树的算法，空间消耗从O(n) 可以变成 O(1)，主要是将一个节点 **左子树** 中 **最右边** 的节点(**根节点的前驱节点**) 变成 **根节点** 再遍历。



正常的遍历需要把每次遍历的节点放入 栈 中，遍历 左子树 后再拿出来遍历 右子树。

因为一般遍历完左子树没法回到根节点所以才需要栈来存储根节点。

**算法步骤**

1. 先判断当前根节点是否有 **左子树**(**左子节点**)。

   * 如果没有左子树，**①** 那么 说明已经到了 **左子树的最左** root = root.right 。

   * 如果有左子树，那么判断一下 **左子树** 的 **最右节点**  是否连接着 **根节点**。
     * 如果没被链接(当前根节点左子树还没被遍历)，那么将 **左子树** 的 **最右节点**  的右孩子变成 **根节点**。**②**遍历左孩子 root = root.left。
     * 如果已经链接好(左子树已经被遍历，并且已经从这个链接回到根节点)，**③** 断开连接，root = root.right。

2. 在存在左子树并遍历左子树的时候，每个节点都要按照1的步骤重新判断，直到root == null。



**代码模板**

以下是 **中序遍历(左中右)** 的模板

先左后右，那么需要在 ①. 完成左子树遍历后，回到根节点前记录 ③. 完成左子树遍历后，回到根节点后记录

```java
public List<Integer> inorderTraversal(TreeNode root) {
        //初始化res保存结果
    	List<Integer> res = new ArrayList<Integer>();
        //初始化前驱节点。
    	TreeNode pre = null;

    	//遍历结束的条件是root == null;
        while(root != null){
            
            //对应步骤1中判断左子树是否为null
            if(root.left != null){
                pre = root.left;
                while(pre.right != null && pre.right != root){
                    pre = pre.right;
                }

                if(pre.right == null){
                    pre.right = root;
                    root = root.left;
                }else{
                    pre.right = null;
                    res.add(root.val);
                    root = root.right;
                }
            }else{
                res.add(root.val);
                root = root.right;
            }
        }
        return res;

    }

```





以下是 **前序遍历**(**中左右**) 的模板

先左后右，那么需要在 ①. 完成左子树遍历后，回到根节点前记录 ②. 还没开始遍历左子树，刚新建连接时记录

```java
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<Integer>();
        TreeNode pre = null;

        while(root != null){
            if(root.left != null){
                pre = root.left;
                while(pre.right != null && pre.right != root){
                    pre = pre.right;
                }

                if(pre.right == null){
                    res.add(root.val);
                    pre.right = root;
                    root = root.left;
                }else{
                    root = root.right;
                }

            }else{
                res.add(root.val);
                root = root.right;
            }
    }
    return res;
}

```
