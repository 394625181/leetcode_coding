# 不同数据结构之间的转换



char[]、String、StringBuilder 

``` java
//char[] 转 String
String str = new String(chr);

//String 转 char[]
char[] chr = str.toCharArray();

//String 转 StringBuilder
StringBuilder stb = new StringBuilder(str);

//StringBuilder 转 String
String str = stb.toString();

```



int、Integer、String

``` java
//int 转 Integer
Integer itg = new Integer(i);
Integer itg = Integer.valueOf(i);

//Integer 转 int
int i = Integer.intValue(itg);

//int 转 String
String str = String.valueOf(i);
String str = ""+i;

//String 转 int
Integer itg = Integer.valueOf(str);
int i = Integer.intValue(itg);
//或者
int i = Integer.parseInt(str);
```





int[]、Integer[]、ArrayList<Integer>、 HashSet<Integer>

``` java
//int[] 转 Integer[]
Integer[] itgs = Arrays.stream(arr_int).boxed().toArray(Integer[]::new);

//Integer[] 转 int[]
int[] ints = Stream.of(itgs).mapToInt(Integer::intValue).toArray();

//int[]转 ArrayList<Integer>
List<Integer> list1 = Arrays.stream(arr).boxed().collect(Collectors.toList());
List<Integer> list1 = IntStream.of(arr).boxed().collect(Collectors.toList());

//ArrayList<Integer> 转 int[]
int[] ints = lis.stream().mapToInt(Integer::intValue).toArray();

//Integer[] 转 ArrayList<Integer>()
List<Integer> list = new ArrayList(Arrays.asList(itgs));

//ArrayList<Integer> 转 Integer[]
Integer[] itgs = lis.toArray(new Integer[0]);

```
