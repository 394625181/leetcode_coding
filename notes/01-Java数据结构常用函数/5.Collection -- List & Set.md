# Collection

Collection是一个接口，其子接口包含 List 和 Set



``` java
//因为是接口，所以只包含 抽象接口方法。
//下述方法都以 lis 对象为例， 可以是List也可以是Set
//转化为对应数组 以int为例  返回的是一个Object数组。
Object[] array = lis.toArray();
//如果想要定义类型，需要传入一个等数组 长度随意。
Integer[] array = lis.toArray(new Integer[0]);
//如果想要基础数据类型需要从IntStream流中获取
int[] array = lis.stream().mapToInt(x->x).toArray();

//查询集合大小
int size = lis.size();

//增添单个元素
lis.add(E e);

//增添一个list或者set里的所有元素，希望复制一个完整的list请用addAll();
lis.addAll(Collection<E> lis_new);

//查询list或set中是否包含 指定元素
boolean res = lis.contains(E e);

//查询list或set中是否包含 指定集合中的所有元素
boolean res = lis.containsAll(Collection<E> lis_new);

//删除元素,以int为例    注意List接口将int参数的remove()方法进行重写。
boolean res = lis.remove(int i);

//删除所有元素
lis.clear();

//判断集合是否为空
boolean res = lis.isEmpty();


```





# List -- 有序列表

List接口是Collection接口的一个子接口。

``` java
//常用方法
//List接口 继承了 Collection接口的 上述方法，下面列出一些List额外增加的一些方法。

//按 给定位置新增 元素
lis.add(int index,E element);

//按 给定位置新增 列表元素
lis.addAll(int index,Collection lis);

//按 给定位置 修改列表元素
lis.set(int index,E e);

//查询 给定索引的 元素值
E element = lis.get(int index);

//查询 给定元素 第一次出现的索引
int index = lis.indexOf(Object obj);

//查询 给定元素最后一次出现的索引
int lastIndex = lis.lastIndexOf(Object obj);

//删除 给定索引的元素
lis.remove(int index);

//获取 子list
List<E> subList = lis.subList(int begin,int end);

```





# Set -- 无序集合

Set 下的实现类 中的元素全部都是 **无序且不重复的** 。而其并没有重要的自身特有的方法，大多数方法都来自Collection接口。

``` java
//常用方法皆为接口函数
.toArray();   .size();	.add(x);	.addAll(x);	.remove(x);	,contains(x);	.isEmpty()
.clear();

```
