# Map

Map是一个接口，常用实现类有HashMap，表示的是<K ,V> 键值对的集合。

``` java
//常用接口函数
//获得 map中 key 的数量。
int size = map.size();

//清空map
map.clear();

//查询 map 中是否包含 给定key
boolean res = map.containsKey(K key);

//查询 map 中是否包含 给定 value
boolean res = map.containsValue(V value);

//给定key 查询value
V value = map.get(K key);

//给定key 查询value 如果没有就返回一个默认值 (后续使用put()再加入map)
V value = map.getOrDefault(K key, V defaultValue);

//判断map是否为空
boolean res = map.isEmpty();

//向map 中增加 给定key-value对 ,返回被替换的值  注意！会覆盖原有键值对！
V value = map.put(K key, V value);

//向map 中增加给定 old_map 的所有key-value对
map.putAll(Map<K,V> old_map);

//向map 中增加还没有的 key. 如果已经有key,则不添加
map.putIfAbsent(K key, V value);

//删除map中 给定key        也可以给定key-value,只删除给定key 的 给定value
V value = map.remove(K key);
boolean res = map.remove(K key, V value);

//给定key 替换map中的 对应 value
V old_value = map.replace(K key, V new_value);
boolean res = map.replace(K key, V old_value, V new_value);

//返回 key 的集合
Set<K> keySet = map.keySet();

//返回 key-value 的集合
Set<Map.Entry<K,V>> entrySet = map.entrySet();

//返回 value 的集合
Collection<V> values = map.values();


```



# HashMap

HashMap 是 Map 接口的一个实现类，基本常用方法都是Map的接口方法。





# Map.Entry

Map.Entry表示的是map中的键值对对象

通常在增强for循环或迭代器中使用

``` java
//常用方法
//获取 key值
K key = entry.getKey();

//获取 value值
V value = entry.getValue();
    
```
