# Stream

Stream 可以用于处理一组数据，这组数据可以是 数组 、集合

Stream 对象通常用于用多个方法链式处理一组数据 通常是 stream.xxx().xxx().xxxx()

这个时候需要弄明白每个函数的输入和返回值。

这其中大多数函数都需要 使用函数作为参数。

大多方法都返回流本身， 最后一个函数用于选择输出数组、或集合、或map



``` java
//构造方法
//数组构造流
Stream stm = Stream.of(obj[] arr);
Stream stm = Arrays.stream(obj[] arr);

//得到 不同基础类型流的方法
IntStream int_stream = stm.mapToInt(ToIntFunction<? super T> mapper);
LongStream long_stream = stm.mapToLong(ToLongFunction<? super T> mapper)
DoubleStream double_stream = 

//集合构造流
Stream stm = lis.stream();
Stream stm = map.entrySet().stream(); //map通过把 key-value对变成Set来构造流。

//静态方法
//拼接两个流
Stream stm_sum = Stream.concat(Stream<T> stream1,Stream<T> stream2)

//常用 无函数接口的 流中数据处理方法 
//获取 前n个 元素
Stream stm = stm.limit(long n);
    
//去除流冲 前n个 元素
Stream stm = stm.skip(long n);

//将流中的元素去重(使用的是.equals()进行判断)
Stream stm = stm.distinct();
     
//对流中元素进行排序(可以使用自定义排序规则)
Stream stm = stm.sorted();
Stream stm = stm.sorted(Comparator comparator);
     
//获取流中的元素个数
int count = stm.count();
     
//Stream流变为集合、数组
List<E> lis = stm.collect(Collectors.toList());
Set<E> set = stm.collect(Collectors.toSet());
E[] arr = stm.collect(Collectors.toList()).toArray();
```



# 函数式接口

stream中许多操作函数需要通过将函数作为参数才能使用。



## Predicate<T>

下文都用 predicate 表示这个接口的对象

这个接口只有一个抽象接口函数   boolean test(T t); 

有三个default函数  and、or、negate(),但是无法在函数式接口中使用。 

``` java
//使用Predicate接口函数的 stream函数
//其中的predicate 表示 Predicate接口的函数  boolean test(T t); 即输入一个元素返回boolean值。
//判断流中元素是否符合要求
boolean res = stm.allMatch(predicate);
boolean res = stm.anyMatch(predicate);
boolean res = stm.noneMatch(predicate);

//获得符合条件的 元素流
Stream stm = stm.filter(predicate);
```



# Consumer<T>

下文使用consumer 表示这个接口的函数。

这个接口只有一个接口函数  void accept(T t); 

给定一个元素t ， 进行处理后什么也不返回。

``` java
//使用Consumer接口函数的 stream函数
//其中consumer 表示 Consumer接口的函数 void accept(T t);输入元素直接处理。
//对流中每个元素都进行操作(这个函数返回void)(函数链中最后一链)
stm.foreach(consumer);

//对流中每个元素都进行操作，但是返回一个相同的流。
Stream stm = stm.peek(consumer);
```



# Function<T,R>

下文使用function表示这个接口的函数

这个接口只有一个接口函数  R apply(T t);

给定一个元素t，通过一系列处理返回一个 R类 的对象。

``` java
//使用Function接口函数的 stream函数
//其中function 表示 Function接口的函数 R apply(T t);
//将Stream流转化为其子类 IntStream流
IntStream intStm = stm.mapToInt(consumer);
stm.mapToInt(x->x);

//将Intstream流 变为 Integer[]
stm.toArray(consumer);
stm.toArray(x->new Integer(x));
```







# IntStream

这是 Stream的一个子类，流中全都是int。

``` java
//构造方法
//一般有Stream来或者其他Stream来
IntStream intStream = stm.mapToInt(x->x);

//常用方法
//求和、最大值、最小值、平均值、总数
int sum = stm.sum();
int max = stm.max();
int min = stm.min();    
int avg = stm.average();
int count = stm.count();

//装箱
Stream<Integer> integerStm = intStream.boxed();
```
