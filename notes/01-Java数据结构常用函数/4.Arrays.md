# Arrays

Arrays 是一个 java 自带的工具类，可以将数组处理为List.

``` java
//Arrays 是一个工具类，里面都是静态方法，没有构造函数

//常用方法
//比较两个数组中的 数据 是否相同(必须是1维数组)
boolean res = Arrays.equals(T[] a1, T[] a2);

//比较两个数组中的 数据 是否"深度相同"(多维数组必须使用这个)
boolean res = Arrays.deepEquals(T[][] a1, T[][] a2);

//将数组内容复制到 新的指定长度的数组中。 如果指定长度短则截取，如果指定长度长则填充(并不是用0填充)
T[] new_arr = Arrays.copyOf(T[] old_arr, int new_length);

//复制 指定数组 的 一部分
T[] new_arr = Arrays.copyOfRange(T[] old_arr,int begin,int end);

//将 指定数组 用 指定数值进行填充
Arrays.fill(char[] chr_array, char chr);

//数组排序
Arrays.sort(int[] int_array);
Arrays.sort(char[] chr_array);



//!!!别用
//!!!别用!!!将 指定数组 变为列表。  注意列表中的泛型一定 不能是基础数据类型。！！！别用
List<T> list = Arrays.asList(T[] array)	
/*
尽量别用
1.这个参数中的数组必须将 基础数据类型 变为包装类。 不然无法变为 List
2.使用这个方法进行转化后的结果不是 ArrayList,而是Arrays的一个内部类。没有add,remove,clear等方法
3.改变这个得到的 list 中的 元素顺序 居然会打乱原数组中元素的顺序。
*/
List<T> lis = new ArrayList<T>(Arrays.asList(array)); //不能用！！！尤其是基础数据类型！   
//或者,必须注意泛型应为包装类。 
List<T> lis = new ArrayList<T>();
Collections.addAll(lis,arr);
//这个也不能用！！！！
```
