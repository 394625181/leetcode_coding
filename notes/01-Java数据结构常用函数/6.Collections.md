# Collections 工具类

与Arrays一样，Collections工具类中的方法全都是 静态方法，用于处理集合。



``` java
//常用方法 (都是静态方法)

//向 集合 中 插入给定元素
boolean res = Collections.addAll(Collection<E> c, E e1, E e2...);

//检查集合中是否有相同元素	不同返回true   相同返回false
boolean res = Collections.disjoint(Collection<E> c1, Collection<E> c2);

//统计一个元素在 给定集合 中出现的次数
int res = Collections.frequency(Collection<E> c1, E e);
    
//返回 给定集合 中的最大值
E e = Collections.max(Collection<E> c1);
    
//返回 给定集合 中的最小值
E e = Collections.min(Collection<E> c1);
 


//List专用操作方法    
//替换列表中的 给定元素
boolean res = Collections.replaceAll(List<E> lis, E old_e, E new_e);    
    
//翻转列表
Collections.reverse(List<E> lis); 
    
//随机打乱 给定列表
Collections.shuffle(List<E> lis);    
    
//为给定列表进行排序
Collections.sort(List<E> lis);    
  
//交换 给定列表中 给定两个索引位置的元素
Collections.swap(List<E> lis,int i, int j);  

//复制 list
Collections.copy(List<E> lis1, List<E> lis2);

//使用 给定元素 填充 List
Collections.fill(List<E> lis, E e);

//返回 给定源列表中 目标列表第一次出现的索引
int index = Collections.indexOfSubList(List<E> lis_source, List<E> lis_target);
    
//返回 给定源列表中 目标列表最后一次出现的索引
int index = Collections.lastIndexOfSubList(List<E> lis_source, List<E> lis_target);
```
