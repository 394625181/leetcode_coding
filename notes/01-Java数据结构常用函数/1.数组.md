## 常用函数

``` java
//构造函数
char[] chr = new char[25];

//获取长度(属性)
chr.length;

//变成字符串
Arrays.toString(chr);   //输出形式是[x, x, x]

//转换为字符串
String str = new String(chr); //输出形式是xxx
```
