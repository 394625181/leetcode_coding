# 字符串

## 常用方法

``` java
//构造方法  直接使用char[]或byte[]进行创建，
//可以加两个参数，一个表示起始位置，另一个表示字符串长度
String str1 = new String(char[] chr);
String str2 = new String(byte[] bt);
String str1 = new String(char[] chr,int begin,int count);
String str2 = new String(byte[] bt,int begin,int count);


//静态方法
//字符串拼接 第一个参数表示分隔符，余下参数为拼接字符串。
String str = String.join(String delimiter,String str1,String str2...);

//基础数据类型数组转换为字符串
String str = String.valueOf(char[]);
String str = String.valueOf(char[],int begin,int count);
//与构造函数类似
//可以转化数值类型的数据。
String str = String.valueOf(int);
String str = String.valueOf(boolean);
String str = String.valueOf(double);
String str = String.valueOf(float);



//常用方法
//查询 指定索引的 字符
Char chr = str.charAt(i);

//字符串的拼接
String con = str1.concat(str2);    //结果是str1 str2

//查询子字符串是否在字符串中
boolean res = str.contains(charSequence subStr);

//检查 指定子字符串 第一次出现的索引
int index = str.indexOf(String str);	//没有则会返回-1
int index = str.indexOf(String str,int fromIndex); //可以指定从第一个索引开始

//查询 指定子字符串 最后一次出现的索引
int index = str.lastIndexOf(String str);
int index = str.lastIndexOf(String str,int fromIndex);

//查询是否以 指定子字符串 开头
boolean res = str.startsWith(String begin);
boolean res = str.endsWith(String end);

//检查是否为空
boolean res = str.isEmpty();

//返回字符串长度
int len = str.length();

//将 指定子字符串 替换为 新字符串
String str_replace = str1.replace(CharSequence target, CharSequence replacement);
//根据正则表达式进行 子字符串 替换
String str_replace = str1.replaceAll(String regex, CharSequence replacement);

//将字符串根据 指定分隔符 进行分割，返回字符串数组
String[] splitStr = str.split(String regex);
String[] splitStr = str.split(String regex,int limit);//限制拆分后的个数

//获取 子字符串
String subStr = str.substring(int beginIndex, int endIndex);

//字符串 转为字符数组
char[] chr = str.toCharArray();

//更改字符串中字符的大小写
String low_str = str.toLowerCase();
String upper_str = str.toUpperCase();

//删除字符串的前后空格
String new_str = str.trim();

//取得字节序列，以便用于字节流
byte[] bt = str.getBytes();
byte[] bt = str.getBytes(String charsetName); //可以指定字符集

//查看字符串是否符合给定的正则表达式
boolean res = str.matches(String regex);

//查询 CharSequence 类型变量的内容是否与 字符串 内容相同
boolean res = str.contentEquals(CharSequence chr);
```





## StringBuffer & StringBuilder

String 是不可变长度的，而StringBuffer则长度可变，因此进行字符串拼接的时候可以节省时间和空间。

而StringBuilder 因为不保证同步因此比StringBuffer还要快。

``` java
//构造函数
StringBulider sbu = new StringBuilder();
StringBulider sbu = new StringBuilder(String str);

//常用方法
//插入 指定子字符串 或 字符数组，在最后插入
StringBuilder sbu = sbu.append(char[]);
StringBuilder sbu = sbu.append(char[],int begin,int end); //可以插入部分字符数组
StringBuilder sbu = sbu.append(String str);
StringBuilder sbu = sbu.append(String str,int begin,int end);//插入部分子字符串
//功能相同的插入，指定插入位置
StringBuilder sbu = sbu.insert(int index,String str);


//删除 指定索引 的子字符串
StringBuilder sbu_del = sbu.delete(int start,int end);

//查询 指定索引 的字符
char chr = sbu.charAt(int index);

//更改 指定索引 位置的字符
StringBuilder new_sbu = sbu.setCharAt(int index,char ch);

//删除 指定索引 的字符
StringBuilder new_sbu = sbu.delete(int begin,int end);
StringBuilder new_sbu = sbu.deleteCharAt(int index);


//字符串翻转
StringBuilder sbu_reverse = sbu.reverse();

// substring()函数和 replace()函数与String 相同。 

```
