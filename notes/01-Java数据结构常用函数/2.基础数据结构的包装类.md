表示数值的包装类都实现自Number类，因此共同享有一些抽象方法。







## Integer

``` java
//构造函数
Integer i = new Integer(int i);   //可以是int或者字符串形式的int,但不能是小数。

//接口方法,与Byte,Short,Float,Double共用的方法。
//Integer转换为其他类型的基础数据。
byte bt = i.byteValue();
short st = i.shortValue();
double d = i.doubleValue();
float v = i.floatValue();

//Integer 转 int
int i = Integer.intValue(itg);

//静态方法无需实例化，直接使用Integer.xxx()进行调用。
//取最大值,等同于Math.max();
int x = Integer.max(int i, int j);

//取最小值,等同于Math.min();
int x = Integer.min(int i, int j);

//比较两个整数.  1为>   0为=    -1为<
int x = Integer.compare(int i,int j); 

//字符串转为int
int x = Integer.parseInt(String str);

//int转字符串
String str = Integer.toString(int i);

//string或int转Integer
Integer it = Integer.valueOf(int i);
Integer it = Integer.valueOf(String str);

//基础数据类型数组 转 包装类数组
Integer[] boxedArray = Arrays.stream(basicArray).boxed().toArray(Integer[]::new);
```
