# 链表



首先定义链表节点如下：

```java
class Node{
    Node next;
    int val;
    
    Node(){}
    
    Node(int val){
        this.val = val;
    }   
}
```



根据输入的数组构造头节点，然后得到链表头：

```java
 public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Node lis1 = new Node(Integer.MIN_VALUE)
        Node lis2 = new Node(Integer.MIN_VALUE);
        String[] strs1 = in.nextLine().split(" ");
        String[] strs2 = in.nextLine().split(" ");  
        Node head1 = lis1, head2 = lis2;
        for(String str:strs1){
            head1.next = new Node(Integer.parseInt(str));
            head1 = head1.next;
        }
        
        for(String str:strs2){
            head2.next = new Node(Integer.parseInt(str));
            head2 = head2.next;
        }
        
        Node new_lis = combine(lis1.next, lis2.next);
        
        while(new_lis != null){
            System.out.print(new_lis.val + " ");
            new_lis = new_lis.next;
        }
        
    }
```
